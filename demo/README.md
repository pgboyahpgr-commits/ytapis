# ytapis Demo

GitHub Pages demo for **ytapis** — a YouTube search API that requires no API key.

- Fetches video data from the [Cloudflare Worker](https://ytapis.djalokyt27.workers.dev/) backend
- Trending + Search tabs with responsive card layout
- Click any video to open on YouTube
- Works offline via service worker

Deploy the `demo/` folder to GitHub Pages (set source to `/demo` in repo settings).
